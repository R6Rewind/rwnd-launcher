# RWND Launcher

Source code of the RWND launcher, version 1.2.67, shared so people can review what it does.

This is a read-only copy. Build files, live settings, the code that starts the game, the code that patches game files, some game fixes and the anti-cheat are left out, so it cannot be compiled into a working launcher.

Get the official installer from [Releases](../../releases) and compare its SHA-256 with `SHA256SUMS.txt`.

Read how the [anti-cheat](ANTICHEAT.md) works.
