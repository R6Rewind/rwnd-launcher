# Anti-cheat

While the game runs, the RWND anti-cheat checks the game for cheats. RWND's servers also run their own checks, which are not described here. The anti-cheat code is not in this repository, so cheat makers cannot study it.

## What it collects

- Your PC's hardware identifiers, stored as hashes
- Windows security settings
- Details of the software loaded inside the game
- A fingerprint of the RWND launcher that started the game
- Samples of suspicious code found in the game's memory
- Counts of simulated input
- Basic details of programs that open the game or draw over it

## How it is used

This data is used only to detect cheating and enforce bans. Only RWND staff can see it. It may be kept longer than other data so that bans keep working.

Full details are in the [Privacy Policy](https://rwnd.gg/legal/privacy).
